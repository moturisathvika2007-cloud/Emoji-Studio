# 🎨 Emoji Studio

Emoji Studio is a simple and interactive web application that allows users to create and customize emojis. Users can select different expressions and interact with the emoji through an easy-to-use interface.

## ✨ Features

* 😊 Happy expression
* 😢 Sad expression
* 😡 Angry expression
* 😮 Surprised expression
* 🔄 Reset emoji
* 🖥️ Simple and user-friendly interface
* ⚡ Interactive buttons using JavaScript
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the web application
* **CSS3** – Provides styling, layout, and visual design
* **JavaScript** – Adds interaction and changes the emoji expression

## 🚀 How to Run

### Method 1: Using a Browser

1. Download or clone this project.
2. Open the `Emoji-Studio` folder.
3. Double-click `index.html`.
4. The application will open in your browser.
5. Click the expression buttons to interact with the emoji.

### Method 2: Using VS Code

1. Open the `Emoji-Studio` folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Right-click inside the HTML file.
5. Select **Open with Live Server**.
6. The application will open in your default browser.

## 🎮 How to Use

1. Open Emoji Studio.
2. View the emoji in the preview section.
3. Select an expression:

   * 😊 Happy
   * 😢 Sad
   * 😡 Angry
   * 😮 Surprised
4. The emoji changes according to your selection.
5. Click **Reset** to return to the default expression.
